BEFORE (Broken):
  303-570-9810  →  +3035709810  ❌ Missing country code!

AFTER (Fixed):
  303-570-9810  →  +13035709810  ✅ Correct!

The format_phone_number method now:
  1. Strips all formatting (spaces, dashes, parens)
  2. Checks if already has + prefix → keep as-is
  3. If 10 digits → add +1 (US/Canada)
  4. If 11 digits starting with 1 → add +
  5. Otherwise → add + prefix

EXAMPLES:
  ✅ '303-570-9810'      → '+13035709810'
  ✅ '3035709810'        → '+13035709810'
  ✅ '13035709810'       → '+13035709810'
  ✅ '+13035709810'      → '+13035709810'
  ✅ '(303) 570-9810'    → '+13035709810'
  ✅ '1 720 575 2095'    → '+17205752095'
  ✅ '+1 720 575 2095'   → '+17205752095'
  ✅ '303 570 9810'      → '+13035709810'
